# 考场纸面设计说明

阶段 0 评审稿。样张位于 [frontend/public/style-sample.html](../../frontend/public/style-sample.html)，可在前端开发服务器的 `/style-sample.html` 打开。作答进度、成绩和倒计时是示例数据，实操题面采用题库 2.2.1 的公开标题与工作任务节选。

工作台按「继续作答 → 开始一套 → 查看成绩」组织。续答区像一张待完成的答卷，左侧写卷名和当前题，右侧对齐进度、剩余时间和继续入口。两个科目用相同的字段顺序呈现规则，方便横向比较。答题界面延续这套排版，用纸面、细线和留白区分题面、导航和答题字段。宋体用于卷名和章节标题，工具与题干使用黑体。

## 字体、尺寸与操作层级

阶段 1 默认改用本地字体栈。标题使用 `"Noto Serif SC", "Source Han Serif SC", "Songti SC", STSong, "SimSun", serif`，正文使用 `"Noto Sans SC", "Source Han Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`。代码采用系统等宽栈。时间、分数和题号用 `tabular-nums`，界面使用实际可用的 400、600、700 字重。

首轮评审采用系统字体。若后续要统一跨平台的宋体字形，可将标题及导航固定文案所用的汉字、标点和拉丁字符收成字集，仅打包实际使用的字重，以 WOFF2、`unicode-range` 和 `font-display: swap` 自托管，合计不超过 300 KB。未覆盖的动态题名和题干继续走系统字体。

| 阶梯 | 数值 | 使用位置 |
| --- | --- | --- |
| 字号 | 12 / 14 / 16 / 18 px | 元数据、标签、正文、题干 |
| 标题 | 22 / 28 / 36 / 48 px | 小节、科目、工作台标题、宽屏展示 |
| 行高 | 标题 1.2–1.35，正文 1.6–1.75 | 保持题干和长选项可扫读 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px | 标签、控件、区块依次放大 |
| 圆角 | 4 / 6 px | 题号、按钮、卡片。胶囊用于状态 |
| 按钮高度 | 常规至少 40 px，小号 32 px | 主要动作和表内动作。窄屏主要触控入口至少 44 px |

| 按钮层级 | 样式 | 示例 |
| --- | --- | --- |
| 主操作 | 墨蓝实底白字 | 继续作答、下一题、保存 |
| 次操作 | 纸白底、可辨认的边框 | 开始练习、上一题、取消 |
| 交卷／危险 | 交卷红底白字，删除红色描边 | 交卷、删除答卷 |
| 文字操作 | 无边框，悬停加下划线 | 查看考核方案、查看全部答卷 |

工作台有进行中答卷时，「继续作答」占用页面唯一的蓝色实底。样张将卡内的「开始模拟考试」降为浅蓝底配蓝色边框，保留它在本卡内的优先级。无进行中答卷时，两卡各自的「开始模拟考试」可以使用蓝色实底。样张把这个冲突处理作为本轮评审项。

## 公共组件

- `UiButton` 和 `UiCard` 统一层级、尺寸、焦点和间距。按钮支持链接、普通操作与禁用状态。
- `StatusTag` 展示进行中、已交卷、已阅卷、未答、已答、部分作答和已标记等状态。
- `ExamTopBar` 与 `CountdownClock` 显示卷名、进度、剩余时间、答题卡入口和交卷。最后 10 分钟加上红色与「时间将到」，最后 1 分钟仅一次轻微提示，尊重减少动态效果设置。
- `AnswerSheet` 用文字或符号表示当前、已答、未答、部分作答、标记。当前题可与其他状态叠加。理论沿用题型分组，实操展示题号、题名、分值。
- `ConfirmDialog` 汇总未答和标记，初始焦点落在「返回检查」，Esc 关闭，关闭后焦点回到触发按钮。
- `SaveIndicator` 支持保存中、已保存及时间、失败及重试。实操附件另提示「只保存在这台浏览器」。
- `EmptyState` 与 `LoadingBlock` 提供空、加载和出错的占位。重新登录后回原答卷的交互方案需独立验证当前前端路由及会话约束。
- 首页和账号共用答卷行展示规则。名称与打开路径由同一处决定，理论与实操分别进入对应答题页。
