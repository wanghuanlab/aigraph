# 前端改版方案

给执行改版的智能体用。先读完本文，再读 `AGENTS.md`、`.agents/conventions.md`、`.cursor/rules/dev-servers.mdc`。

## 目标

站点是备考者每天用的模拟考场，不是营销页。改版要做到三件事：

1. 全站只有一套视觉语言。
2. 首页变成考生工作台，登录后先看到“继续作答”和成绩。
3. 两个答题页的计时、进度、交卷一眼可见，交卷有确认，作答有保存反馈。

只改样式、模板结构和纯前端交互。不改接口、考试规则和数据结构。

## 现状诊断

2026-11-09 在 1440 宽度下逐页检查得出。

### 全局

| 问题 | 位置 |
| --- | --- |
| 两套设计语言：主站是灰蓝底、宋体、印章红；理论答题页是亮蓝 `#2f6fed` 顶栏、橙色 `#f5a623` 按钮、12px 圆角卡片 | `frontend/src/styles.css`、`frontend/src/views/TheoryWorkspace.vue` 的 `<style scoped>` |
| 没有设计变量：只有 10 个颜色变量，没有字号、间距、圆角、状态色 | `styles.css` 第 1–17 行 |
| 品牌 Logo 是指向 `/` 的 `router-link`，在首页也命中 `.router-link-active`，带着选中底色，像个按钮 | `SiteHeader.vue`、`styles.css` 的 `.top a.router-link-active` |
| 字体走 Google Fonts，国内经常加载失败；CSS 用了字重 650，但只加载了 600 和 700 | `frontend/index.html`、`styles.css` 的 `h1, h2, h3` |
| 底色 `#e8eef2` 和卡片色 `#fbfcfd` 太接近，边框又淡，内容区分不开 | `styles.css` |
| 按钮全是胶囊形，主按钮、次按钮、危险操作看不出层级 | `.btn`、`.btn.seal`、`.btn.ghost` |

### 首页 `HomeView.vue`

- 操作技能和理论知识是两个结构相同的 `.hero` 竖着堆，右侧两张方案卡连在一起，像一根长条。
- “账号里的答卷”放在最底下。行内文字居中，留白太大，状态没有颜色，分数不突出，看不出能点。
- “01 组卷、02 作答、03 阅卷”是说明性内容，在每天打开的首页上作用不大。

### 操作题答题页 `WorkspaceView.vue`

- 计时器是左栏一个小红字，快到时间也没有任何提醒。
- 左栏题号只有 `1.2.4` 这样的编号，没有题名和分值；完成状态只是一个 8px 小点。
- 交卷按钮只在最后一题出现，点了也没有二次确认。理论页有确认，这里没有。
- 底部 `.bar` 是半透明的，会盖住题干文字。
- 答题框只有 120px 高，没有字数，也没有“已保存”提示。
- 题干栏底色发灰，三栏之间界线不清。

### 理论答题页 `TheoryWorkspace.vue`

答题卡、标记、图例、未答提醒都已经有了，交互比操作题页完整。问题只在视觉和主站不一致。改版保留这些交互，换成统一的视觉。

### 学习资料 `MaterialsView.vue`

- 左栏模块只显示 `1.1`、`1.2`，没有名称；模块和题目混在一个列表里，层级不清。
- 代码每行一个灰色块（`NoteTree.vue` 每个节点一个 `<pre>`），读起来零碎。
- 没有搜索。

### 账号 `AccountView.vue` 和后台 `AdminView.vue`

- 登录表单只占左边一窄条，右边大片空白。
- 账号页的修改密码和答卷列表挤在同一页。
- 后台统计数字只是一条横线加小字，不像数据看板。

### 改版时要一起修的前端缺陷

- 账号页答卷列表：`exam.mode === 'exam' ? '模拟考试' : '全题练习'`，理论答卷也会显示成“全题练习”；“打开”一律跳 `/workspace/...`，理论答卷打不开。改成复用首页 `paperName` 的逻辑，理论卷跳 `/theory/:id`。最好抽成 `frontend/src/exam/` 下的共享函数。
- `NoteTree.vue` 里所有图片的 `alt` 都写死成 2.2.1 那张建模流程图的说明。改成按笔记标题生成，或者在 `examNotes.json` 里给图片补说明字段。

### 不在本次范围，另开任务

- 验证码 SVG 的字符可以从 DOM 直接读出，机器人能绕过。这是后端生成方式的问题。
- `admin` 仍是初始密码。不要替用户改。

## 视觉方向：考场纸面

沿用 `.agents/conventions.md` 的约定，“墨色、一张试题单、一个印章红”，做得更彻底：

- 页面是一张米白答题纸，不再用冷灰蓝。
- 墨色正文，深蓝只用于主操作，印章红只用于强调、警示、计时告急、交卷。
- 标题用宋体，正文用黑体，数字用等宽数字（`font-variant-numeric: tabular-nums`）。
- 用细线、留白和纸张层次区分区域，阴影只用在浮层上。
- 圆角统一 4–6px。胶囊形只留给状态标签，不用在按钮上。

### 设计变量

写在 `styles.css` 的 `:root` 里，所有页面只用这些变量。下面的数值是起点，可以微调，但要保证正文对比度不低于 WCAG AA（4.5:1）。

```css

  --sheet: #fffdf8;        /* 卡片、答题纸 */
  --sheet-sunk: #efebe1;   /* 代码块、表头、只读区 */
  --line: #e0d9c9;
  --line-strong: #c9bfaa;

  /* 文字 */
  --ink: #1c2026;
  --ink-2: #444b55;
  --muted: #6b7079;

  /* 操作与状态 */
  --blue: #1f4e8c;
  --blue-hover: #183f72;
  --blue-soft: #e6edf6;
  --seal: #b23a2e;
  --seal-soft: #f7e7e3;
  --ok: #2f7a4d;
  --ok-soft: #e5f1e9;
  --warn: #a8670f;
  --warn-soft: #f8eedb;

  --font-serif: "Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", serif;
  --font-sans: "Noto Sans SC", "Source Han Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
  --font-mono: ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;

  /* 字号阶梯 */
  --fs-xs: 12px; --fs-sm: 14px; --fs-md: 16px; --fs-lg: 18px;
  --fs-xl: 22px; --fs-2xl: 28px; --fs-3xl: 36px; --fs-4xl: 48px;
```

### 按钮层级

| 类型 | 用途 | 样式 |
| --- | --- | --- |
| 主按钮 | 每屏最多一个：开始考试、保存、下一题 | `--blue` 实底白字 |
| 次按钮 | 上一题、取消、返回 | `--sheet` 底、`--line-strong` 边框、墨色字 |
| 危险/交卷 | 交卷、删除 | `--seal` 实底白字；删除用 `--seal` 描边 |
| 文字按钮 | 行内辅助操作 | 无边框，悬停出下划线 |

所有按钮高度 40px（小号 32px），圆角 `--radius`，有 `:hover`、`:active`、`:disabled`、`:focus-visible` 四种状态。

## 公共组件

放在 `frontend/src/components/`，两个答题页和其他页面共用：

- `UiButton`：上面四种按钮，加大小号。
- `UiCard`：纸面卡片，可选标题栏。
- `StatusTag`：进行中、已交卷、已阅卷、未答、已标记，各配一种状态色。
- `ExamTopBar`：答题页顶部固定条，放试卷名、进度、倒计时、交卷按钮。
- `CountdownClock`：倒计时，最后 10 分钟变红，最后 1 分钟轻微闪动一次。
- `AnswerSheet`：答题卡，题号格子，区分未答、已答、部分作答、已标记、当前五种状态，附图例。
- `ConfirmDialog`：自定义确认框，替代 `window.confirm`。要能聚焦锁定，Esc 关闭。
- `SaveIndicator`：显示“保存中…”“已保存 hh:mm”“保存失败，重试”。
- `EmptyState`、`LoadingBlock`：空状态和骨架屏。

不引入 UI 组件库，不加新的 npm 依赖。

## 逐页规格

### 顶部导航 `SiteHeader.vue`

- 左边品牌，右边导航。Logo 不参与选中态，给 `router-link` 加 `exact-active-class` 或单独写样式。
- 当前页用下划线或深色文字表示，不用色块。
- 右侧用户名点开是菜单：账号、退出。
- 答题页不显示站点导航，由 `ExamTopBar` 代替。

### 首页（工作台）

从上到下：

1. **继续作答**：有进行中的答卷时显示，列出试卷名、已答/总题数、剩余时间（考试卷才有），一个“继续”主按钮。没有就不显示。
2. **两张入口卡并排**：理论知识、操作技能各一张。卡上写题量、时长、满分，配“开始练习”（次按钮）和“开始模拟考试”（主按钮）。考核方案表格放在卡里，可以展开收起。
3. **最近成绩**：最多 6 行，每行是试卷名、状态标签、分数（大号等宽数字）、时间。整行可点，悬停有反馈，左对齐。
4. 未登录时，入口卡照常显示，点开始跳登录；成绩区换成登录引导。
5. 去掉“01 组卷、02 作答、03 阅卷”，或者改成入口卡下方一行小字说明。

文案保留现有事实（40 题、900 题、6 题 100 分 120 分钟、190 题 90 分钟），数字不要改。

### 两个答题页（统一布局）

```
┌──────────────────────────────────────────────────────────┐
│ ExamTopBar：试卷名 · 进度 12/190 · 倒计时 47:18 · [交卷] │
├───────────┬──────────────────────────────┬───────────────┤
│ 答题卡    │ 题干（答题纸）                │ 答题区        │
│ 题号格子  │                              │（仅操作题）   │
│ 图例      │                              │               │
├───────────┴──────────────────────────────┴───────────────┤
│ 底部导航：[上一题]        保存状态        [下一题]       │
└──────────────────────────────────────────────────────────┘
```

共同要求：

- 顶部条固定，任何一题都能交卷。交卷前弹 `ConfirmDialog`，写明未答题数和标记题数。
- 倒计时最后 10 分钟变红。
- 底部导航条用实底，题干末尾留出足够的下边距，不被遮挡。
- 支持键盘：左右方向键切题；理论题用 1–4 / A–D 选项。

操作题页另外：

- 答题卡格子显示题号、题名（截断）、分值，左边一条细色带表示完成状态。
- 题干栏是白色答题纸，最大宽度约 72 个汉字，下载材料做成显眼的附件块。
- 答题框自动增高，最小 200px，显示字数。
- 文件上传做成拖放区，显示已选文件和“只保存在这台浏览器”的说明。
- 阅卷结果放在答题区顶部，分数大号显示，评语在下面。

理论题页另外：

- 保留现有的分组折叠答题卡、标记、图例、练习卷核对答案。
- 选项做成整行可点的卡片，选中时 `--blue` 边框加 `--blue-soft` 底；核对后正确用 `--ok`，错误用 `--seal`。
- 删除 `TheoryWorkspace.vue` 里写死的颜色，全部换成设计变量。

### 学习资料

- 左栏两级：模块（编号 + 名称），展开后是题目（编号 + 题名）。模块名称从 `examNotes.json` 的标题或子节点里取，取不到时在前端补一张映射表。
- 左栏顶部加搜索框，按题号和题名过滤。
- 正文是答题纸样式，标题层级清楚。同一节下相邻的代码行合并成一个代码块，带等宽字体和复制按钮。
- 980px 以下左栏改成顶部下拉选择。

### 账号

- 未登录：居中卡片，宽约 400px，登录/注册切换用下划线标签页，验证码图和输入框同一行。
- 已登录：左边账号信息和修改密码，右边或下面是答卷列表（复用首页成绩行组件，带删除）。
- 修复上面“改版时要一起修的前端缺陷”。
- `mustChangePassword` 时，修改密码放在最上面，用 `--warn-soft` 的提示条。

### 后台

- 顶部三张数字卡：账号数、自测作答、答卷数。
- 账号列表做成表格：用户名、角色、自测数、答卷数、最近活动。
- 阅卷模型设置放在一张卡里，表单最大宽度 560px。API Key 只显示末四位，这条规则不变。

### 响应式和可访问性

- 断点 980px：所有多栏布局变单栏；答题页的答题卡收进顶部条的一个按钮，点开是抽屉。
- 所有可交互元素有可见的 `:focus-visible`。
- 颜色不是唯一的状态信号，状态标签同时有文字。
- 图片有 `alt`，图标按钮有 `aria-label`。

## 不能改

- 考试规则：操作题 6 题、100 分、120 分钟，分组和分值在 `frontend/src/exam/session.ts`；理论 190 题、100 分、90 分钟，判断 40、单选 140、多选 10。只读这些文件，不改。
- `frontend/src/api.ts` 的请求方式和 `/api/...` 路径。
- 上传文件只存在浏览器 IndexedDB（`frontend/src/exam/files.ts`）。
- 学生端不渲染题库的 `hidden` 块，不展示表格的 `note`（`QuestionBody.vue`）。
- 后端、数据库、`database/seed/` 都不碰。
- 不提交、不推送、不部署，除非用户明确要求。

每个阶段做完都停下来，截图交给用户确认，再进入下一阶段。

## 运行和验证

- 前端开发服务器通常已在终端里运行。没有的话在仓库根目录执行 `npm --prefix frontend run dev`，页面在 `http://127.0.0.1:5173/`。端口被占用时先停掉旧进程。
- 后端只通过 IDEA 运行配置 `AigraphApplication` 启动，不要在终端执行 `mvn spring-boot:run`。细则见 `.cursor/rules/dev-servers.mdc`。
- 本地测试账号：用户名 `admin`，密码 `admin`。登录要验证码，看截图识别。账号会提示修改初始密码，不要改。
- 不要为测试去开新的考试卷，除非必要；账号里已有进行中和已交卷的操作题答卷可以直接打开。需要看理论答题页时，可以开一套理论练习，看完在账号页删掉。
- 每改完一页，在 1440×900 和 390×844 两种宽度下截全页图自查：对齐、文字溢出、对比度、遮挡。
- 交付前执行 `npm --prefix frontend run build`，不能有类型错误。

## 给执行智能体的提示词

### 总提示词

一次性交给执行智能体，让它按阶段推进：

```text
你是资深产品设计师兼 Vue 前端工程师。请按 docs/requirements/frontend-redesign.md 改版本仓库 frontend/ 下的「人工智能训练师（三级）考场」前端。

开始前先读：
1. docs/requirements/frontend-redesign.md（本次改版的全部规格、约束、阶段和验收清单）
2. AGENTS.md、.agents/conventions.md、.cursor/rules/dev-servers.mdc
```
