# AIGraph

人工智能在线知识体系与实战研习平台。站点：[aigraph.wanghuanlab.com](https://aigraph.wanghuanlab.com)

面向国家职业技能等级认定「人工智能训练师（三级 / 高级工）」备考与工程实践，把 Python 考点、真题项目、API 手册和互动自测做成可检索的知识图谱。

## 功能

- **Python 实战考点**：覆盖 1.1.1 至 3.2.5 共 20 套考核项目脉络
- **真题研习**：按知识点浏览题目与解析
- **核心 API 手册**：备考常用接口速查
- **易错点与互动自测**：针对高频坑点做即时练习
- **后续模块**：机器学习、深度学习 / 大模型、模拟考场

## 技术栈

- React 18 + TypeScript
- Vite 6
- Tailwind CSS

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 仓库说明

公开仓库只包含站点源码（`src/`）及构建配置。本地讲义、Notebook 与练习目录不纳入版本库。
